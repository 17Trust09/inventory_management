Inventoryverwaltung als Docker-Container auf Unraid.

2. Container neu bauen & starten

Raspberry Pi (Kumpel)

systemd-Service in venv. Nach Update startet der Pi automatisch neu.

SSH-Verbindung
ssh pi@100.84.57.80
1. Code aktualisieren
cd /home/pi/inventory_management
git pull origin fix/ui-bugs-und-ajax
2. Migrationen + Statics
source venv/bin/activate
python manage.py migrate
python manage.py collectstatic --noinput
3. Service neustarten
sudo systemctl restart django_inventory.service
REBOOT_AFTER_UPDATE=true ist gesetzt. Der Pi startet nach dem Update automatisch neu.
Port: 8000 | DB: PostgreSQL | Tailscale: 100.84.57.80
